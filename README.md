# money-management

A robust personal finance tracking application built with modern technologies.

## Tech Stack
### Core Technologies
- Backend: Node.js with TypeScript
- Database: PostgreSQL
- Containerization: Docker & Docker Compose

### Additional Technologies
- ORM: TypeORM
- API Documentation: Swagger/OpenAPI
- Testing: Jest & Supertest
- Authentication: JWT with refresh tokens
- Validation: class-validator
- Caching: Redis
- CI/CD: GitHub Actions

## Architecture
- Clean Architecture Pattern (Controllers, Services, Repositories)
- Dependency Injection
- Event-Driven Architecture for notifications and reports

## Security Features
- Rate limiting
- Security headers (helmet.js)
- Input sanitization
- CORS policies
- Data encryption
- Audit logging

## Development Practices
- Environment-based configurations
- Development, staging, and production environments
- Pre-commit hooks for code quality
- Strong TypeScript typing

## MVP Features
1. User Management
   - Registration and authentication
   - Profile management
   - Password reset functionality

2. Transaction Management
   - Create, read, update, delete transactions
   - Basic categorization
   - Transaction search and filtering

3. Basic Budget Management
   - Set monthly budgets
   - Track expenses against budgets
   - Basic spending alerts

4. Basic Reporting
   - Monthly expense summary
   - Category-wise breakdown
   - Basic financial insights
